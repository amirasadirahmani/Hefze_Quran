> به‌روزرسانی نسخهٔ ۰٫۲: برای استفادهٔ عادی، صوت را از داخل برنامه دریافت کنید. این راهنما دربارهٔ تهیهٔ زمان‌بندی کلمه‌ای است؛ فایل‌های مرجع صوت را روی سیستم توسعه نگه دارید و به گیت نفرستید.

# تحویل صوت و زمان‌بندی

یاسین سورهٔ **۳۶** و دارای **۸۳ آیه** است. عدد ۳۶ فایل و پیشوند 037 در پروپوزال اشتباه است و در پیاده‌سازی اصلاح شده است.

## فایل‌هایی که باید ارسال شوند

برای آزمون اولیه سه صوت اول را بفرستید؛ در نهایت یک فایل برای هر آیه:

```text
app/src/main/assets/audio/036/036-001.mp3
app/src/main/assets/audio/036/036-002.mp3
...
app/src/main/assets/audio/036/036-083.mp3
```

- یک قاری ثابت؛ هنگام ارسال نام قاری و منبع فایل‌ها را هم بنویسید.
- MP3 سالم، ترجیحاً mono و 64kbps یا بالاتر با کیفیت مناسب، بدون موسیقی یا توضیح فارسی. نرخ نمونه‌برداری را تغییر ندهید مگر لازم باشد.
- هر فایل فقط یک بار تلاوت همان آیه را داشته باشد؛ تکرار توسط خود برنامه انجام می‌شود.
- بسم‌الله شمارهٔ آیه نمی‌گیرد. اگر در ابتدای صوت آیهٔ ۱ هست، همان‌جا بماند و زمان اولین کلمه بعد از آن ثبت شود. بسم‌الله روی صفحه نمایش داده می‌شود اما هایلایت کلمه‌ای مستقل ندارد.
- اگر فقط یک فایل کامل سوره دارید، آن را همراه نام قاری بفرستید؛ ابتدا باید آیه‌ها دقیق جدا شوند. بستهٔ فعلی ابزار جداسازی خودکار یا مدل تشخیص تلاوت ندارد.
- از نسخهٔ ۰٫۲، رابط «دریافت صوت» فایل‌ها را از EveryAyah دریافت و در فضای خصوصی برنامه ذخیره می‌کند. MP3های assets فقط مرجع تولید زمان‌بندی هستند و با تنظیم Gradle وارد APK نمی‌شوند؛ افزودن JSON زمان‌بندی هنوز به rebuild نیاز دارد.

## قرارداد JSON

قالب‌های همهٔ آیات از قبل در `app/src/main/assets/timings/036/` موجودند. مثال ساختاری زیر زمان واقعی تلاوت نیست و نباید به‌عنوان alignment استفاده شود:

```json
{
  "schemaVersion": 1,
  "surah": 36,
  "ayah": 1,
  "reviewed": false,
  "audioSha256": null,
  "durationMs": null,
  "words": [
    {"index": 0, "text": "يسٓ", "startMs": null, "endMs": null}
  ]
}
```

`index` صفرمبنا است و باید با فهرست `words` در `content/yasin.json` دقیقاً یکسان باشد. حرف‌به‌حرف/اعراب‌به‌اعراب تطابق لازم است. `startMs` شامل و `endMs` غیرشامل است؛ در سکوت بین دو کلمه، کلمهٔ فعال وجود ندارد. پایان کلمهٔ قبل باید از شروع بعدی بیشتر نباشد. زمان‌های مرزی نسبت به ابتدای فایل MP3 همان آیه محاسبه می‌شوند، نه ابتدای سوره.

`audioSha256` مانع استفاده از زمان‌بندی صوت قدیمی با فایل جدید است. `reviewed=true` را فقط بعد از بازشنوی و بازبینی مرزها ثبت کنید. اگر زمان‌بندی ناقص، بدون تأیید، نامنطبق با متن یا متعلق به صوت دیگر باشد، صوت می‌تواند پخش شود اما هایلایت کلمه‌ای خاموش می‌ماند. رنگ ملایم آیهٔ انتخاب‌شده فقط نشان‌دهندهٔ انتخاب است.

## ابزار آفلاین علامت‌گذاری

1. `tools/align_words.html` را در Chrome یا Safari باز کنید. اینترنت لازم نیست.
2. قالب JSON آیه را انتخاب کنید و سپس MP3 با نام دقیق همان آیه را باز کنید.
3. هنگام پخش، S شروع کلمه و E پایان کلمه و رفتن به بعدی را ثبت می‌کند. این کلیدها وقتی مکان‌نما در فیلد ورودی نیست کار می‌کنند. سرعت بازبینی را می‌توان کاهش داد؛ زمان‌ها همچنان بر اساس موقعیت اصلی فایل ثبت می‌شوند.
4. با «شنیدن» هر کلمه را بازشنوی کنید و اعداد میلی‌ثانیه را اصلاح کنید. سکوت‌ها را به کلمهٔ مجاور تحمیل نکنید.
5. پس از بررسی تمام مرزها، گزینهٔ تأیید را بزنید و JSON را دریافت کنید. ابزار hash صوت و طول فایل را خودش درج می‌کند.
6. JSON خروجی را جای فایل هم‌نام در پوشهٔ timings بگذارید. فایل MP3 را در مسیر بالا بگذارید و مجدداً build کنید.

اگر مرورگر دسترسی SHA-256 را برای file:// فعال نکرد، از یک سرور محلی استفاده کنید:

```bash
cd tools
python3 -m http.server 8765 --bind 127.0.0.1
```

سپس `http://127.0.0.1:8765/align_words.html` را باز کنید. فایل‌ها فقط داخل مرورگر پردازش می‌شوند و فرم آپلود سرور وجود ندارد.

## اعتبارسنجی

```bash
python3 tools/validate_assets.py
python3 tools/validate_assets.py --release
```

حالت development نبود صوت/زمان‌بندی را گزارش می‌کند اما شکست نمی‌خورد. حالت release حضور همهٔ صوت‌ها و زمان‌بندی معتبر را الزامی می‌کند. این بررسی جای گوش‌دادن و آزمون decoder روی گوشی را نمی‌گیرد. تنها تطابق ساختاری، پوشش کلمات، ترتیب مرزها و hash را بررسی می‌کند.

برای نمونهٔ سه‌آیه‌ای، در اپلیکیشن «برنامهٔ تمرین ← محدودهٔ دلخواه ← ۱ تا ۳» را انتخاب کنید. موارد پذیرش شامل تغییر آیه در میانهٔ صوت، قطع وسط سکوت، بازگشت از پس‌زمینه و مطابقت هایلایت است. بدون فایل‌های واقعی، کیفیت هم‌زمانی قابل تأیید نیست.
