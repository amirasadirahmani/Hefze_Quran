# حفظ یاسین برای اندروید

پیاده‌سازی اولیهٔ آفلاین پروپوزال حفظ قرآن برای سورهٔ یاسین، شامل ۸۳ آیه، رابط فارسی و راست‌به‌چپ، صفحه‌بندی ثابت، موتور تکرار و مکث و ذخیرهٔ محلی پیشرفت.

**وضعیت تحویل:** سورس در Android Studio قابل بازکردن است. ساخت APK آزمایشی و Android Lint در GitHub Actions با موفقیت انجام شده‌اند؛ فایل در Artifact اجرای موفق قرار دارد. نصب و آزمون روی گوشی هنوز انجام نشده است. صوت واقعی و زمان‌بندی تأییدشده هنوز در بسته نیستند. هنگام نبود صوت، برنامه پیام روشن نشان می‌دهد و مطالعه/آزمون/ثبت دستی فعال می‌ماند.

## اجرا روی macOS با Apple Silicon

1. پوشهٔ پروژه را در Android Studio باز کنید. Gradle JDK را روی JDK 17 یا Embedded JDK سازگار تنظیم کنید.
2. در SDK Manager، Android SDK Platform 35 و Build Tools 35.0.0 را نصب کنید. Gradle Sync برای بار نخست به اینترنت نیاز دارد. برنامه در زمان اجرا کاملاً آفلاین است.
3. برای شبیه‌ساز روی Apple Silicon، تصویر ARM64 با Android API 26 یا جدیدتر انتخاب کنید؛ یک گوشی واقعی هم مناسب است.
4. دکمهٔ Run را بزنید. برای ساخت APK از ترمینال داخل پروژه:

```bash
chmod +x gradlew tools/test_core.sh
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
export ANDROID_HOME="$HOME/Library/Android/sdk"
./gradlew :app:assembleDebug :app:lintDebug
```

اگر JDK جداگانه نصب نیست، در ترمینال می‌توانید مسیر JDK همراه Android Studio را تنظیم کنید:

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`. بستهٔ debug برای آزمایش است؛ کلید امضای انتشار در پروژه وجود ندارد.

## استفاده

- پس از اسپلش سه‌ثانیه‌ای، نام، سن و روش حفظ ثبت می‌شوند. هفت روش، پیش‌فرض تعداد تکرار، سکوت و متن پنهان را تعیین می‌کنند. ترجمه و موضوع‌بندی هنوز پیاده نشده‌اند و در توضیح روش‌ها این محدودیت آمده است.
- صفحه‌ها با فونت Amiri همراه برنامه و سطرهای ذخیره‌شده رسم می‌شوند. تغییر عرض دستگاه فقط مقیاس را تغییر می‌دهد. شش صفحهٔ این نسخه، صفحه‌بندی اختصاصی برنامه هستند؛ با صفحات مصحف مدینه یا نسخهٔ چاپی دیگری یکسان فرض نشوند.
- با لمس متن یا «انتخاب آیه» آیه را انتخاب کنید. دکمه‌های قبل/بعد، تکرار همان آیه، تکرار ۱ تا ۱۰ و سکوت ۰ تا ۳۰ ثانیه فعال‌اند. تنظیمات را می‌توان برای آیهٔ جاری یا همهٔ آیات ذخیره کرد.
- «برنامهٔ تمرین» محدودهٔ روزانه یا دلخواه می‌سازد؛ موتور در پایان آن متوقف می‌شود. «مرور فردا» آیه را برای روز بعد در فهرست مرور قرار می‌دهد. مرور موعدرسیده با انتخاب آیه باز می‌شود؛ صف مرور پراکندهٔ خودکار وجود ندارد.
- «خودم تکرار کردم» فقط تکرار دستی را ثبت می‌کند. پخش صوت، خودکار آیه را حفظ‌شده علامت نمی‌زند. «حفظ کردم» خودارزیابی کاربر است.
- برنامه هنگام رفتن به پس‌زمینه، تماس/از دست‌دادن تمرکز صوت یا جداشدن هدفون مکث می‌کند. پخش پس‌زمینه خارج از این نسخه است. بازگشت از پس‌زمینه نیاز به زدن پخش دارد.
- آیه، محدوده، تنظیمات و موقعیت صوت ذخیره می‌شوند. پس از مرگ فرایند، آیه از موقعیت صوت ذخیره‌شده ادامه می‌یابد اما شمارهٔ تکرار از یک آغاز می‌شود؛ در همان فرایند، باقی‌ماندهٔ مکث و تکرار حفظ می‌شود.
- پیشرفت شامل خودارزیابی حفظ، تعداد جلسات، زمان شنیدن بدون سکوت، پخش کامل و تکرار دستی است. جلسه از نخستین شنیدن/تکرار شروع و هنگام خروج از برنامه خاتمه می‌یابد. تاریخ محور نمودار فعلاً میلادی است.
- یادآوری اختیاری حدود ساعت ۲۰ محلی و غیر دقیق است؛ مجوز اعلان فقط هنگام فعال‌کردن آن درخواست می‌شود. پس از reboot لازم است برنامه یک بار باز شود.

## تحویل صوت و تصویر

راهنمای صوت و JSON: [docs/AUDIO_HANDOFF.fa.md](docs/AUDIO_HANDOFF.fa.md)

برای شروع، سه فایل `036-001.mp3`، `036-002.mp3` و `036-003.mp3` از یک قاری ثابت کافی‌اند؛ ساختار برای همهٔ ۸۳ آیه آماده است. پیش‌فرض تمرین را برای این نمونه روی آیات ۱ تا ۳ بگذارید. ابزار آفلاین `tools/align_words.html` با بازکردن در مرورگر امکان ثبت دستی مرز کلمات، بازشنوی و خروجی JSON دارای SHA-256 می‌دهد.

تصویر برای اجرای این نسخه لازم نیست. قاب، پس‌زمینه و آیکن با کد و VectorDrawable ایجاد شده‌اند. پرامپت پیشنهادی یک تصویر اختیاری و روش اتصال آن در [docs/ASSETS.fa.md](docs/ASSETS.fa.md) آمده است.

## ساختار

```text
app/src/main/java/ir/hefze/quran/
  MainActivity.java       رابط، ثبت‌نام و مسیرهای مطالعه
  QuranPageView.java      رندر متن واقعی با چیدمان ثابت
  QuranRepository.java    آیات و اعتبارسنجی زمان‌بندی
  AudioController.java    اتصال MediaPlayer به صف و مدیریت چرخهٔ عمر
  StudyStore.java         SQLite و گزارش جلسات
  ReminderReceiver.java   یادآوری اختیاری محلی
  ProgressChartView.java  نمودار هفت روز
  core/                  ماشین حالت مستقل و قابل تست
app/src/main/assets/
  content/yasin.json      متن، کلمات و شش صفحهٔ ثابت
  audio/036/             جای ۸۳ فایل MP3
  timings/036/           ۸۳ قالب زمان‌بندی بدون زمان تخمینی
  fonts/                 Amiri و مجوز OFL
```

Java 17 و Android APIهای داخلی انتخاب شده‌اند؛ وابستگی اجرایی ثالثی لازم نیست. `minSdk=26` و `target/compileSdk=35`؛ AGP 8.9.2 با Gradle 8.11.1 تثبیت شده است. این انتخاب ادعای استفاده از آخرین نسخه نیست. سازگاری ساخت طبق [مستند رسمی AGP 8.9](https://developer.android.com/build/releases/agp-8-9-0-release-notes) انتخاب شده است. MediaPlayer طبق [مرجع رسمی](https://developer.android.com/reference/android/media/MediaPlayer) پشت یک adapter مستقل قرار دارد.

## بررسی‌ها

```bash
./tools/test_core.sh
python3 tools/validate_assets.py
python3 -m unittest discover -s tests -v
java tools/ParseJava.java app/src/main/java
```

قبل از انتشار بستهٔ کامل:

```bash
python3 tools/validate_assets.py --release
./gradlew :app:assembleDebug :app:lintDebug
```

در وضعیت فعلی `--release` عمداً خطا می‌دهد: ۸۳ صوت و ۸۳ زمان‌بندی تأییدشده موجود نیست. `test_assets.py` به وضعیت پایهٔ بدون صوت وابسته نیست؛ تست‌ها با fixture بدون صوت اجرا می‌شوند. زمان‌بندی تنها با `reviewed=true`، تطابق کلمات، مرزهای معتبر و SHA-256 همان صوت فعال می‌شود. JSONهای فعلی `null` دارند و زمان‌بندی ساختگی نیستند.
