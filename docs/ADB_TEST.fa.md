# نصب و آزمون نسخهٔ ۰٫۴ روی گوشی با adb (macOS)

ابزار موردنظر `adb` است. APK آزمایشی با شناسهٔ `ir.hefze.quran.review05` نصب می‌شود و کنار نسخه‌های قبلی قرار می‌گیرد؛ لازم نیست برنامهٔ قبلی یا داده‌هایش را پاک کنید. Android 8 / API26 یا بالاتر لازم است. نسخهٔ آزمایشی debuggable است تا گزارش و فایل‌ها با run-as قابل بررسی باشند؛ برای انتشار عمومی از این بسته استفاده نکنید.

## ۱. پیدا کردن adb موجود

چون قبلاً APK ساخته‌اید، ابتدا Android SDK موجود را استفاده کنید:

```bash
"$HOME/Library/Android/sdk/platform-tools/adb" version
```

اگر موجود بود، در همین پنجرهٔ Terminal:

```bash
export PATH="$HOME/Library/Android/sdk/platform-tools:$PATH"
adb version
```

اگر SDK در مسیر دیگری است، مسیر Android SDK Location را از Android Studio → Settings → Languages & Frameworks → Android SDK بردارید و `platform-tools` آن را به PATH اضافه کنید. اگر هیچ SDK ندارید، بستهٔ رسمی macOS را از https://developer.android.com/tools/releases/platform-tools دانلود و unzip کنید؛ سپس مسیر پوشهٔ platform-tools آن را به PATH اضافه کنید. نصب مجدد Android Studio لازم نیست.

## ۲. آماده‌کردن گوشی

در Settings → About phone روی Build number هفت بار بزنید. سپس در Developer options، USB debugging را روشن کنید. گوشی را با کابل دارای قابلیت انتقال داده به مک وصل کنید، قفلش را باز کنید و پیام Allow USB debugging را تأیید کنید.

```bash
adb devices -l
```

باید مقابل شناسهٔ گوشی `device` ببینید. `unauthorized` یعنی تأیید روی گوشی باقی مانده است؛ `offline` را با بازکردن قفل و اتصال مجدد کابل بررسی کنید. اگر دستگاهی دیده نشد، کابل/پورت و حالت USB را بررسی کنید. در macOS معمولاً درایور سازنده لازم نیست.

اگر چند دستگاه وصل است، در همهٔ فرمان‌ها به جای `adb` از `adb -s SERIAL` استفاده کنید؛ SERIAL همان شناسهٔ خروجی دستور بالا است.

## ۳. نصب و اجرا

APK پیوست را با نام `Hefze-Quran-0.5-review.apk` در Downloads ذخیره کنید:

```bash
adb install -r "$HOME/Downloads/Hefze-Quran-0.5-review.apk"
adb shell am start -n ir.hefze.quran.review05/ir.hefze.quran.FullQuranActivity
```

خروجی نصب باید `Success` باشد. اجرای دوم لازم نیست اگر برنامه را از آیکن «حفظ قرآن» باز کرده‌اید.

برای بررسی نسخه و شناسه:

```bash
adb shell dumpsys package ir.hefze.quran.review05 | grep -E 'versionCode|versionName'
adb shell getprop ro.build.version.release
adb shell wm size
adb shell wm density
```

اگر `INSTALL_FAILED_UPDATE_INCOMPATIBLE` گرفتید، امضای یک نصب قبلی با همین شناسه متفاوت است. حذف برنامه تمام تنظیمات و دانلودهای همان نصب را پاک می‌کند؛ فعلاً آن را حذف نکنید و متن خطا را بفرستید. `INSTALL_FAILED_OLDER_SDK` یعنی Android گوشی از ۸ قدیمی‌تر است. خطای محدودیت نصب را در تنظیمات امنیتی سازنده بررسی کنید.

## ۴. آزمون پیشنهادی (ابتدا سورهٔ کوتاه)

1. در فهرست، «اخلاص» یا ۱۱۲ را جستجو کنید. ورودی باید کادر واضح داشته باشد؛ نام و شماره پررنگ و توضیح زیر آن معمولی باشند. «ادامهٔ مطالعه» تنها نوشته است.
2. تنظیمات را با چرخ‌دنده باز کنید؛ قاری «مشاری العفاسی — آیه‌به‌آیه (ar.alafasy)» را انتخاب کنید. اندازهٔ متن را تغییر دهید، ذخیره کنید و برنامه را دوباره باز کنید؛ انتخاب‌ها باید بمانند.
3. صفحهٔ خواندن: فاصلهٔ جداکننده بین هر آیه نباشد. آغاز سوره عنوان جدا دارد. قاب بالا در حالت عمودی و افقی بررسی شود؛ متن نباید از قاب بیرون بزند.
4. دریافت صوت: فقط «دریافت سوره»، ضربدر قرمز بالای چپ و توقف زرد سمت راست پیشرفت دیده شود. شروع، توقف وسط دانلود، تلاش مجدد و بستن پنجره را امتحان کنید. فایل کامل دوباره دانلود نمی‌شود. بستن پنجره دریافت را لغو نمی‌کند؛ خروج از خود برنامه آن را متوقف می‌کند.
5. پس از تکمیل، اینترنت را قطع کنید. دکمه‌های آیهٔ قبل، پخش/مکث، تکرار و آیهٔ بعد باید جای «دریافت صوت» باشند. پخش متوالی و تکرار همان آیه را بررسی کنید. مکث و ادامه باید از همان نقطه باشد.
6. سوره‌ای بلندتر مانند یس را دریافت کنید؛ در اندازهٔ متن بزرگ، آیهٔ در حال پخش باید برجسته و در محدودهٔ دید نگه داشته شود. این هماهنگی آیه‌ای است، نه کلمه‌ای. عبور از مرز صفحه نیز باید صفحهٔ بعد را باز کند.
7. قاری را تغییر دهید: نباید صدای قاری قبلی پخش شود؛ برای قاری جدید باید جداگانه دریافت کنید. یک نسخهٔ «سورهٔ کامل» را نیز امتحان کنید؛ چون منبع زمان‌بندی آیه ندارد، دکمه‌های آیه و اسکرول همراه صوت در آن عمداً غیرفعال‌اند و فقط پخش/مکث فایل کامل فعال است.
8. دکمهٔ خانه باید فهرست را باز کند و پخش متوقف/مکث شود. خروج از برنامه، قفل صفحه، تماس یا جداکردن هدفون نباید باعث ادامهٔ ناخواستهٔ صوت شود.

## ۵. گرفتن لاگ هنگام خطا

ابتدا برنامه را باز کنید. سپس لاگ همان process را ذخیره کنید:

```bash
QURAN_PID=$(adb shell pidof -s ir.hefze.quran.review05 | tr -d '\r')
adb logcat --pid="$QURAN_PID" -v threadtime > "$HOME/Desktop/hefze-quran-log.txt"
```

خطا را تکرار و با Ctrl+C ثبت لاگ را تمام کنید. اگر برنامه قبل از گرفتن PID کرش می‌کند، لاگ کرش را بگیرید:

```bash
adb logcat -b crash -d -v threadtime > "$HOME/Desktop/hefze-quran-crash.txt"
```

اسکرین‌شات و مشخصات:

```bash
adb exec-out screencap -p > "$HOME/Desktop/hefze-quran-screen.png"
adb shell getprop ro.product.model
adb shell getprop ro.build.version.release
```

فایل لاگ را پیش از ارسال برای اطلاعات شخصی احتمالی مرور کنید. همراه آن، نام/شناسهٔ قاری، سوره، آیه، اندازهٔ فونت و مراحل تکرار خطا را بنویسید.

## ۶. بررسی پوشهٔ دانلودها

این نسخه آزمایشی debuggable است و run-as برایش فعال است:

```bash
adb shell run-as ir.hefze.quran.review05 ls -R files/recitations
adb shell run-as ir.hefze.quran.review05 du -k files/recitations
```

نمونهٔ مسیر: `files/recitations/ar.alafasy/112/001.mp3`. نسخه‌های سوره‌ای فایل `surah.mp3` دارند. فایل `.part` فقط هنگام دریافت موقت است و پس از لغو عادی پاک می‌شود. در توقف اجباری سیستم ممکن است فایل موقت باقی بماند؛ دریافت بعدی آن را بازنویسی می‌کند. این پوشه خصوصی برنامه است و در فایل‌منیجر عمومی نمایش داده نمی‌شود.

برای گرفتن نسخهٔ پشتیبان از داده‌های همین نسخهٔ آزمایشی، بدون حذف هیچ چیز:

```bash
adb exec-out run-as ir.hefze.quran.review05 tar -cf - files shared_prefs > "$HOME/Desktop/hefze-quran-review-backup.tar"
```

این دستور را پس از بازکردن برنامه و ذخیرهٔ تنظیمات و دریافت حداقل یک صوت اجرا کنید تا مسیرها وجود داشته باشند.

مرجع رسمی adb: https://developer.android.com/tools/adb
